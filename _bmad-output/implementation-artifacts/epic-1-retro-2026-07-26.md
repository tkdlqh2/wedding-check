## 핵심 패턴 (스토리 기록 종합)

1. **외부 인프라 공백은 매번 착수 시점에 발견된다** — Neon DB(1.1), Vercel Blob(1.4). DB는 해결, Blob은 미해결.
2. **로컬 검증 방식(Node fetch)과 안전장치(`requireAdminSession`, 2-hop 재검증)는 한 번 배우면 이후 스토리에 그대로 재사용됨** — 좋은 복리 효과.
3. **코덱스 리뷰가 실질 가치를 냄** — 특히 로컬 전용 드라이버로는 절대 못 잡는 프로덕션 전용 버그(`db.transaction()`)를 1.3에서 잡아냈고, 1.4의 UX 타이밍 이슈도 3라운드에 걸쳐 점진적으로 정확해짐.
4. **자동화 테스트 없이 수동 검증만으로 여기까지 왔다** — 지금까지는 버텼지만, Epic 2부터는 인스턴스 생성(AD-9 부분집합 매칭)·오프라인 캐시(AD-5)처럼 상태 조합이 훨씬 많아져 수동 검증 비용이 급격히 커질 수 있음.

**결론: Epic 2 착수 가능. Vercel Blob 프로비저닝과 테스트 전략 재검토만 별도 트랙으로 인계.**
